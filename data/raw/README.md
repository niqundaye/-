# Raw Data Folder

Place the released spatial-unit dataset here:

```text
spatial_units_xi_ujimqin_2023.csv
```

For public verification, this table should contain one row per spatial analysis unit and the columns listed in the root `README.md`.

The demo-data generator creates a deterministic synthetic verification table with the same schema. That file is useful for testing the code but should not be described as the original remote-sensing dataset.
