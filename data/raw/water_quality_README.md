# Water-Quality Monitoring Appendix Data

`water_quality_monitoring_long.csv` is extracted from the supplied monitoring appendix DOCX.

The file contains river and tributary water-quality monitoring results for June 2023, September 2023, and April 2024. It is useful as supporting environmental-monitoring evidence for ecological background and water/wetland constraint discussion.

It is not a substitute for the spatial-unit LST modeling table required to reproduce Figure 4, because Figure 4 depends on LST, NDVI, bare-land proportion, land-use intensity, SVF, nighttime light, elevation, and other spatial predictors.

Recommended use in this repository:

- Archive as supplementary raw monitoring evidence.
- Join to monitoring locations only if station coordinates are available.
- Use for water-environment background, ecological-sensitive-area validation, or appendix-level transparency.
