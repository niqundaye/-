# Data and Code Availability Statement

The source code and reproducibility materials are available in this repository.

The repository contains:

- source code for model fitting, interpretation, spatial potential assessment, multi-objective allocation, trade-off analysis, and water-quality monitoring summaries;
- a data dictionary for the required spatial-unit table;
- a Google Earth Engine script for reconstructing public remote-sensing predictors;
- public data-source documentation;
- real supplementary water-quality monitoring data extracted from the monitoring appendix.

For full manuscript reproduction, the harmonized spatial-unit table should be provided as:

```text
data/raw/spatial_units_xi_ujimqin_2023.csv
```

If any township statistics, local planning layers, industrial-land datasets, or high-resolution morphology data are subject to redistribution restrictions, the repository should retain the aggregated spatial-unit variables and document the restricted source metadata.
